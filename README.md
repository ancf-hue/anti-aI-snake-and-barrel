# 🐍🛢️ Анти ИИ: Змея и Бочка (Anti-AI: Snake and Barrel)

> **Бесплатный социальный офлайн-проект** в рамках инициативы «Anti-AI Shield» и серии «25 игр про Змею».  
> Развивает реакцию, точность мышления и цифровую осознанность через увлекательную 3D-механику.

## 🎮 О игре
Вы управляете спуском бочки с фиолетовой горы. К бочке привязана умная красная змея, которая реагирует на ваши действия. Ваша задача — контролировать скорость спуска с помощью тормоза, чтобы пройти через ворота на безопасной скорости и не разбить бочку. Собирайте бонусы, ставьте рекорды и доберитесь до погреба за отведенное время!

Игра не использует интернет для геймплея, не собирает данные и не содержит встроенной аналитики, что соответствует философии защиты от цифровых угроз и манипуляций.

## ✨ Особенности
- 🎯 **Уникальная физика**: Реалистичная инерция, система торможения и динамическая шкала безопасной скорости.
- 🐍 **Живой компаньон**: 3D-змея меняет цвет при торможении или идеальном прохождении, высовывает язык и физически корректно следует за бочкой.
- 📱 **Кроссплатформенность**: Полная адаптация под мобильные устройства (тач-управление, виброотклик, поддержка `safe-area`) и десктоп (управление пробелом).
- 🎨 **Стильная графика**: Three.js, стеклянный UI (glassmorphism), система частиц, динамическое освещение и тени.
- 🔊 **Иммерсивный звук**: Синтез звуковых эффектов через Web Audio API (без внешних файлов) и голосовые подсказки (TTS) на русском и английском языках.
- 🛡️ **Анти-ИИ философия**: Развитие цифровой гигиены, концентрации и защиты от клипового мышления через игровые метафоры.

## 🕹️ Как играть
1. **Цель**: Спуститься на 100% до погреба за 3 минуты, сохранив бочку целой (3 жизни).
2. **Управление**:
   - 📱 **Мобильные**: Удерживайте большую кнопку **ТОРМОЗ** внизу экрана.
   - 💻 **Десктоп**: Удерживайте клавишу `Пробел`.
3. **Механика**: 
   - Следите за правой шкалой **СКОРОСТЬ**. 
   - **Зеленая зона** — безопасное прохождение ворот.
   - **Красная зона** — высокий риск краша (потеря жизни и откат прогресса).
   - Собирайте бонусы: ⭐ замедление времени, 🛡️ щит от краша, ❤️ дополнительная жизнь, 💰 монеты.

## 🛠️ Технологический стек
- **Ядро**: HTML5, CSS3 (адаптивная верстка, glassmorphism), Vanilla JavaScript (ES6+).
- **3D-графика**: [Three.js](https://threejs.org/) (r128).
- **Аудио**: Web Audio API + SpeechSynthesis API.
- **Хранение**: `localStorage` для сохранения локального рекорда.
